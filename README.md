⚡ Harry Potter Web Application (Angular)
Aplicación web desarrollada en Angular como proyecto en 1º del Ciclo Superior de Desarrollo de Aplicaciones Web (DAW). 
La app consume una API de Harry Potter para ofrecer una experiencia interactiva completa sobre el universo mágico, gestionando personajes, películas, libros, hechizos y pociones.

🚀 Tecnologías y Herramientas
  · Frontend: Angular, TypeScript, HTML5, SCSS / CSS3
  · Gestión de Datos: Modelos tipados en TypeScript, Servicios de Angular (HttpClient)
  · Control de versiones: Git & GitHub

🎯 Secciones y Características de la App
  🧙‍♂️ Personajes: Listado completo con fichas detalladas y filtrado de personajes de la saga.
  🎬 Películas: Explorador de las películas del universo cinematográfico con visualización de detalles en formato modal.
  📚 Libros: Sección dedicada a la obra literaria con información detallada de cada volumen.
  ✨ Hechizos y Pociones: Secciones interactivas del mundo mágico (actualmente en fase de desarrollo / ampliación).
  🧭 Navegación: Barra de navegación personalizada y diseño completamente responsive (SCSS).
  
📂 Estructura del Proyecto
  src/app/components/       # Componentes globales (ej. Navbar)
  src/app/pages/hechizos/     # Catálogo de hechizos (En construcción)
  src/app/pages/libros/       # Modelos, servicios y vistas de libros
  src/app/pages/main/         # Página de inicio / bienvenida
  src/app/pages/peliculas/    # Gestión de películas y vista modal de detalles
  src/app/pages/personajes/   # Listados, modelos y servicios de personajes
  src/app/pages/pociones/     # Catálogo de pociones (En construcción)
  src/app/styles/           # Variables y estilos globales en SCSS
  src/app/app.routes.ts     # Enrutamiento de la aplicación
  src/app/app.config.ts     # Configuración global de Angular

🛠️ Instalación y Ejecución en Local
Si deseas clonar y probar este proyecto en tu entorno local, ejecuta en tu terminal:

  git clone https://github.com/antonioprietom/harry-potter-angular.git
  cd "harry-potter-angular"
  npm install
  ng serve
  Abre tu navegador en http://localhost:4200/.
